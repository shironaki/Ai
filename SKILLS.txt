#  УМЕНИЯ АИ
#  Что она действительно делает — тот самый список, который она показывает на
#  «что ты умеешь». Пополняется с каждой сборкой.
# ══════════════════════════════════════════════════════════════════
#
#  КАК УСТРОЕН ДОКУМЕНТ
#
#  сборка: X.Y.Z         для какой сборки список сверен. Перед выпуском сюда
#                        вписывается новое и ставится номер новой сборки —
#                        иначе тесты не пропустят выпуск.
#  == название ==        раздел. «Что ты умеешь» покажет разделы по одной
#                        строке, «что ты умеешь: название» — раздел целиком.
#  слова: …              по каким ещё словам раздел находится; «игр*» — начало слова.
#  коротко: …            строка раздела в общем списке.
#  разбор: …             какие разборы (parse…) и намерения раздел описывает.
#                        Появился в коде новый разбор, а сюда не вписан — тест
#                        назовёт его по имени.
#  Обычная строка        одна строка раздела. Примеры — в «ёлочках»: каждый
#                        цельный пример тест говорит сердцу и проверяет, что
#                        его поняли без модели. Пример с многоточием («напомни
#                        через час …») не проверяется.
#  {ты|вы}               первое — близким на «ты», второе — на «вы».
#
#  Пометки в начале строки или названия раздела, через запятую.
#  От них зависит, кому строка видна:
#    [хозяин]            только хозяину и только в личке
#    [группа] [личка]    только в группе / только в личке
#    [краски]            только когда есть художник (ключ Cloudflare)
#    [секретарь] [сестра]  только когда секретарь включён / сестра рядом
#    [STICKERS]          только когда настройка с таким именем не выключена
#  Только для проверки, на показ не влияют:
#    [модель]            на эти слова отвечает модель — пример не проверяется
#    [ответом]           говорится ответом на сообщение — не проверяется
#    [состояние]         нужна начатая игра, сцена и т. п. — не проверяется
#    [источник]          ответ берётся из сети (Википедия, Deezer…): в тестах
#                        сети нет — не проверяется
#    [чат]               проверять в группе, обращением «Аи, …»
#    [админ]             проверять от имени того, у кого есть права (хозяина)
#
#  После правки:  npm run skills   (соберёт tgcloud/lib/data/skills.js)
