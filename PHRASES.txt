# ══════════════════════════════════════════════════════════════════════════
#  СЛОВАРНЫЙ ЗАПАС АИ
#  То, что она говорит сама, без модели: приветствия, разговор о делах,
#  ответы о себе, вкусы, пасхалки, флирт, слова для манер и настроений.
# ══════════════════════════════════════════════════════════════════════════
#
#  КАК УСТРОЕН ДОКУМЕНТ
#
#  == название ==        начало темы.
#  когда: фраза, фраза   на какие реплики тема отвечает. Реплика должна совпасть
#                        ЦЕЛИКОМ: «привет» — да, «привет, реши задачу» — нет
#                        (такое уйдёт к модели). Регистр, «ё» и знаки не важны.
#  Обычная строка        один вариант ответа. Чем больше строк, тем реже повторы.
#
#  В строке «когда:» можно:
#    (слово)             необязательное слово:   как (у тебя) дела
#    слово/слово         любое из слов:          доброе/доброго утро/утра
#    *                   любые слова (до четырёх): ты * захватишь мир
#
#  В ответе можно:
#    {ты|вы}             первое — близким на «ты», второе — на «вы»:
#                        Как {твои|ваши} дела?
#    {имя}               как человек просил себя звать (нет имени — пропадёт)
#    {настроение} {причина} {час} {дней} {сборка} — подставит программа
#    \n                  перенос строки
#
#  Пометка в начале строки — кому и когда она подходит:
#    [хозяин] [не хозяин]                    только хозяину / всем, кроме него
#    [близко] [тепло] [знакомы] [холодно]    по отношениям с человеком
#    [утро] [день] [вечер] [ночь]            по времени суток у человека
#    [личка] [группа]                        где идёт разговор
#    [флирт]                                 только если с человеком можно флиртовать
#  Несколько пометок — через запятую: [хозяин, ночь].
#  Если человеку холодно с ней и в теме есть строки [холодно] — звучат только они.
#
#  Темы с плюсом (== +манера:кошка ==) — запасы слов: их берёт программа,
#  строки «когда:» у них нет.
#
#  ПОСЛЕ ПРАВКИ:  npm run phrases   (пересобрать)  и  npm run ci  (проверить).
#  Строки с «#» — пояснения, Аи их не читает.

# ──────────────────────────────────────────────────────────────────────────
#  ЗДРАВСТВУЙ И ПРОЩАЙ
