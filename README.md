# Telegram bot

Основной запуск проекта: `main.py`. Скрипт `run.py` запускает его тем же Python-интерпретатором и оставляет логи в текущей консоли.

## Требования

- Python 3.11
- Токен Telegram-бота в переменной окружения `BOT_TOKEN`

## Локальный запуск на Windows

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
$env:BOT_TOKEN = "<токен из BotFather>"
python run.py
```

После успешного подключения в консоли появится сообщение, что бот подключён и ожидает сообщения. Напишите боту в личные сообщения `/start`; список команд открывается через `/help`. На неизвестный текст бот отвечает подсказкой.

## Продолжение работы с телефона через Codespaces

1. Загрузите этот проект в приватный GitHub-репозиторий.
2. В GitHub откройте репозиторий, выберите **Code → Codespaces → Create codespace**. Настройка `.devcontainer` установит Python 3.11 и зависимости.
3. В настройках GitHub Codespaces добавьте секрет с именем `BOT_TOKEN`. Не сохраняйте токен в файлах или коммитах. Перезапустите Codespace после добавления секрета.
4. Откройте Codespace в мобильном браузере и в терминале выполните `bash start.sh`.

## Данные и дополнительные боты

Основной бот создаёт `users.db` и `chats.db` рядом с исходниками. Эти файлы и виртуальные окружения не входят в архив исходников. Папка `levaya papka` содержит отдельные экспериментальные боты; основной `run.py` их не запускает, и для них требуется самостоятельная настройка.
