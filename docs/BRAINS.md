# Запасные мозги: как подключить ключ

Аи думает цепочкой: основные модели (ключ `AI_PROVIDER_KEY`), затем запасные
провайдеры по порядку из `AI_PROVIDERS` в `tgcloud/lib/config.js`. Запасной
провайдер без ключа спит и ничего не стоит. Чтобы его разбудить, нужен только
ключ — код уже написан.

Условия провайдеров меняются. Здесь записано то, что проверено по их
документации 12.11.2026 (Cloudflare — 14.11.2026; лимиты и список моделей
основного провайдера — 15.11.2026, раздел «Когда отвечает запасная»).

**Несколько ключей одного провайдера лимит не увеличивают.** У Groq лимит
считается на организацию (аккаунт), а не на ключ: два ключа делят один и тот
же объём. Несколько аккаунтов (вопрос владельца 15.11.2026) технически дали бы
несколько лимитов, но заводить аккаунты ради обхода лимита запрещено их
правилами: за это блокируют все аккаунты разом, включая основной, — и Аи
останется без главного мозга. Второго ключа основного провайдера код не
принимает, и добавлять это не нужно: тот же результат без риска дают **разные
провайдеры** — у каждого свой бесплатный лимит, и они складываются. Шесть таких
добавлены 15.11.2026 (раздел «Провайдеры из статьи Хабра»): нужен только ключ.
Ещё пути: словарь (на короткий разговор модель не нужна) и платный план.

## Куда кладётся ключ

**На телефоне** (основной путь, см. [PHONE.md](PHONE.md)) — отдельной строкой
в файле `~/.heart.env`, по строке на провайдера:

```
KEY_GIGACHAT=…
KEY_EXPLABS=xpl_…
KEY_CLOUDFLARE=<ID аккаунта>:<токен>
```

Имя после `KEY_` — имя провайдера из таблицы ниже, большими буквами. Скрипт
заметит новый ключ не сам: ключ попадает в Аи только при публикации. Чтобы
опубликовать с новым ключом, остановите скрипт и запустите
`bash scripts/phone.sh deploy`, затем снова `bash scripts/phone.sh`.

**Для кнопки в GitHub Actions** (запасной путь) все ключи лежат в одном
секрете `AI_EXTRA_KEYS` — строка JSON: `{"explabs":"xpl_…","gigachat":"…"}`.
Создаётся там же, где лежит `AI_PROVIDER_KEY`: Settings → Secrets and
variables → Actions. После изменения секрета — Actions → Heart → Run
workflow → `deploy`.

Проверка — сказать Аи **«проверь мозги»**. Она отправит по одному живому
запросу каждой модели и назовёт, кто отвечает, а кто нет и почему.

| Провайдер | Имя в JSON | Строка в `~/.heart.env` | Модели | Что нужно для ключа |
|---|---|---|---|---|
| Experiential Labs | `explabs` | `KEY_EXPLABS` | `deepseek-v4.1-flash:free`, `gpt-6-luna:free` | почта и проверка карты |
| GigaChat | `gigachat` | `KEY_GIGACHAT` | `GigaChat-3-Ultra`, `GigaChat-2-Max`, `GigaChat-2-Pro`, `GigaChat-2` | Сбер ID |
| Mistral | `mistral` | `KEY_MISTRAL` | `mistral-small-latest`, `mistral-large-latest` | почта и телефон |
| Cerebras | `cerebras` | `KEY_CEREBRAS` | `gpt-oss-120b`, `qwen-3.8-27b` | почта |
| Google Gemini | `gemini` | `KEY_GEMINI` | `gemini-3.8-flash`, `gemini-3.5-flash-lite`, `gemini-2.5-flash` | аккаунт Google |
| OpenRouter | `openrouter` | `KEY_OPENROUTER` | `google/gemma-4-31b-it:free`, `openai/gpt-oss-20b:free`, `openrouter/free` | почта |
| NVIDIA NIM | `nvidia` | `KEY_NVIDIA` | `openai/gpt-oss-120b`, `meta/llama-3.3-70b-instruct` | почта и телефон |
| GitHub Models | `ghmodels` | `KEY_GHMODELS` | `openai/gpt-4.1-mini`, `openai/gpt-4o-mini` | аккаунт GitHub |
| Cloudflare Workers AI | `cloudflare` | `KEY_CLOUDFLARE` | Gemma, Llama 3.3 70B, Mistral Small — и рисование | почта; о карте документация не говорит |

Порядок в таблице — порядок, в котором Аи их пробует после основных моделей.

## Cloudflare: рисование и ещё один мозг

Один ключ делает два дела: Аи рисует («нарисуй кота в шляпе») и получает
запасной мозг. Бесплатно — 10 000 «нейронов» в сутки, это входит в бесплатный
план; счёт обнуляется в полночь по UTC (03:00 по Москве). Про карту в
документации ничего нет: попросит ли её кабинет при регистрации — не
проверено. С 0.31.0 картинка рисуется в восемь шагов (предел художника) и
стоит 96 нейронов: 4,80 за плитку 512×512 (их четыре) плюс 9,60 за шаг — цены
со страницы Cloudflare, сверено 15.11.2026. Это примерно сто картинок в сутки,
если не думать этим же ключом. Описание, написанное моделью, — ещё около пяти
нейронов; перевод фразы — доли нейрона.

Как получить (по документации Cloudflare; сами шаги в кабинете вживую не
проверены):

1. Зарегистрироваться на `dash.cloudflare.com` (почта и пароль).
2. В кабинете открыть страницу **Workers AI** и выбрать **Use REST API**.
3. Нажать **Create a Workers AI API Token**, затем **Create API Token** и
   **Copy API Token** — и сразу сохранить токен у себя.
4. Там же скопировать **Account ID** — 32 знака из цифр и букв a–f.
5. В `~/.heart.env` вписать одной строкой, без пробелов:
   `KEY_CLOUDFLARE=<Account ID>:<токен>`.
6. `bash scripts/phone.sh check` — скажет, верно ли записана строка. Затем
   `bash scripts/phone.sh deploy` и снова `bash scripts/phone.sh`.

Проверка: «статус» — строка «Рисование: …»; «проверь мозги» — модели
Cloudflare в списке; «нарисуй кота в шляпе».

Чего ждать: объём кончился — на «нарисуй» она ответит «краски на сегодня
кончились» и назовёт час; ключ отклонён — напишет хозяину. Рисунков на
человека — пять в день (`DRAW_DAILY_PER_PERSON`), хозяину — без счёта.
Описание для художника собирается по порядку: её словарь художника (206
готовых описаний — ничего не стоит) → модель того же ключа пишет описание
(первые две из списка мозга Cloudflare; Gemma — с выключенным «размышлением»,
до 400 токенов, девять секунд) → переводчик `m2m100` на всю просьбу. Перевода
нет — честное «не вышло»: по русским словам художник рисует случайное, и такой
запрос ему больше не уходит. «Статус» называет, кто из них не ответил и что
сказал.

Тем же переводчиком она переводит и для людей («переведи на английский: …») и
ищет перевод к слову без пары («запомни слово apple»).

**Если мастерская отказала** (так было вживую 15.11.2026: «нарисуй кота» —
отказ). Причина из песочницы не установлена: до Cloudflare отсюда не дойти. С
0.30.0 отказ разбирается и показывается:

- хозяину в личке — дословно: какое описание ушло и что ответил каждый
  художник (номер ответа и слова мастерской). Эти строки и есть то, что нужно
  прислать в рабочий чат;
- в «статусе» — строка «Рисование» сутки хранит последний отказ.

Попытки идут по порядку: основной художник (`flux-1-schnell`) с полными
настройками → он же с одним описанием (если отказ не из-за содержания) → с
припиской «illustration, safe for work» и затем описанием без добавок (если
фильтр сработал на безобидном) → запасные художники того же ключа. К запасным
после фильтра идут просьбы хозяина наедине и готовые описания (открытка, её
собственное, строка словаря художника); чужие слова — нет.

**Запасные художники и 20.11.2026.** Сейчас их четыре: FLUX.2 klein
(`flux-2-klein-4b`, около 104 нейронов за картинку, запрос уходит формой) и три
старых — SDXL Lightning, DreamShaper, SDXL. На страницах трёх старых Cloudflare
пишет «Planned Deprecation 11/20/2026» (сверено 15.11.2026). После этой даты
они ответят отказом; запасной, не принявший запрос, отдыхает шесть часов и
назван в строке «Рисование» статуса — мешать он не будет. Что это меняет:

- ложный отказ фильтра на безобидном по-прежнему есть кому перерисовать — FLUX.2
  klein (если он примет форму: это вживую не проверено);
- **откровенное для хозяина наедине рисовать будет нечем**: и основной
  художник, и klein такое не пропускают. Нужен другой поставщик рисунков —
  это решение владельца, сама она его не меняет.

Проверено вживую владельцем 15.11.2026: Cloudflare из облака платформы
доступен, картинка приходит. Не проверено: кто именно и с какой попытки рисует
(с 0.31.0 это видно по слову «как нарисовано?»), пишет ли описание модель,
принимает ли FLUX.2 klein форму.

## Провайдеры из статьи Хабра

Владелец 15.11.2026 прислал статью «Бесплатные API для 150+ ИИ-моделей»
(habr.com/ru/articles/1062238, 23.07.2026). Из неё взяты шесть провайдеров с
OpenAI-совместимым входом и постоянным бесплатным доступом (провайдеры с
разовыми пробными кредитами не взяты: кредит кончится, а запись останется).
Адреса и имена моделей сверены 15.11.2026 по документации провайдеров; сами
запросы из песочницы не проверить — первый «проверь мозги» покажет, кто
отвечает. Каждый ключ — отдельный лимит: они складываются.

| Провайдер | Бесплатный лимит | Где взять ключ | Что знать заранее |
|---|---|---|---|
| **Mistral** | запрос в секунду, 500 тыс. токенов в минуту, 1 млрд токенов в месяц | `console.mistral.ai` → план Experiment → API Keys | самый щедрый; нужен телефон; на бесплатном плане запросы могут идти на обучение моделей |
| **Cerebras** | свой дневной объём на каждую модель (числа — в кабинете) | `cloud.cerebras.ai` → API Keys (ключ начинается с `csk-`) | самый быстрый; две модели |
| **Google Gemini** | у каждой модели свой, считается на проект (числа — в AI Studio, раздел Rate limit) | `aistudio.google.com/api-keys` | бесплатный план есть не во всех странах; запросы на нём могут читать люди Google |
| **OpenRouter** | 20 запросов в минуту и 50 в день на все бесплатные модели вместе; 1000 в день — после пополнения счёта на $10 за всё время | `openrouter.ai` → Keys (ключ начинается с `sk-or-`) | в настройках приватности надо разрешить бесплатные модели, иначе они отвечают «нет подходящих»; состав бесплатных моделей меняется |
| **NVIDIA NIM** | 40 запросов в минуту | `build.nvidia.com` → Get API Key (ключ начинается с `nvapi-`) | при регистрации просят телефон |
| **GitHub Models** | десятки запросов в день, короткие ответы | GitHub → Settings → Developer settings → Fine-grained token с правом «Models: Read-only» | пределы жёсткие — это запас на чёрный день |

С чего начать: **Mistral** (один ключ закрывает почти любой день) и **Cerebras**
или **Gemini**. Остальные — по желанию.

Как подключить любой из них:

1. Получить ключ на сайте провайдера.
2. В `~/.heart.env` вписать строку `KEY_<ИМЯ>=<ключ>` — имя из таблицы выше.
3. `bash scripts/phone.sh check` (должно назвать его среди запасных мозгов),
   затем `bash scripts/phone.sh deploy` и снова `bash scripts/phone.sh`.
4. Сказать Аи «проверь мозги».

Если модель провайдера переименовали или сняли, Аи пропустит её на сутки и
возьмёт следующую; новое имя вписывается в `AI_PROVIDERS` в `config.js`.

Чем больше провайдеров, тем больше третьих сторон видят то, что люди пишут Аи.
Что каждая делает с текстами — в колонке «что знать заранее»; решает владелец,
добавляя ключ.

## Поиск в интернете

С 0.32.0 Аи ищет в сети: по слову («найди в интернете …», «загугли …», «что
пишут про …») и сама — когда на вопрос о мире ответила «не знаю». Найденное —
справка для модели: отвечает она своими словами, а источники под ответом
называет код, не модель.

Чем ищет, по порядку:

| Поисковик | Строка в `~/.heart.env` | Бесплатно | Где взять ключ |
|---|---|---|---|
| Tavily | `KEY_TAVILY=tvly-…` | 1000 запросов в месяц, без карты | tavily.com → Sign up → API Keys |
| Brave Search | `KEY_BRAVE=…` | около 1000 запросов в месяц (5 долларов кредита), **нужна карта** | brave.com/search/api |
| Википедия | ключ не нужен | без счёта | работает всегда |

Без ключей она ищет по Википедии: до трёх статей, у первой вступление целиком.
Это годится для «кто, что, где, когда», но не для свежего: цен, счёта матча,
вчерашних новостей. Для свежего нужен ключ; советую Tavily — он без карты.

Запас бережётся: на день не больше 30 запросов по ключу (`SEARCH_DAILY`), сверх
того — Википедия. Хозяину — без счёта. Сколько ушло, видно в «статус», строка
«Поиск». Выключатель — `SEARCH: false` в `config.js`.

Поисковиков без ключа здесь нет намеренно: DuckDuckGo и Bing ботам не отвечают
или запрещают такое использование правилами (проверено 15.11.2026).

## Experiential Labs

Шлюз с OpenAI-совместимым API. В бесплатном плане две разговорные модели:

| Модель | Что это |
|---|---|
| `deepseek-v4.1-flash:free` | DeepSeek V4.1 Flash — быстрая, усилие рассуждения управляется |
| `gpt-6-luna:free` | GPT-6 Luna — младшая модель OpenAI |

Вместе они делят **миллион токенов в сутки** (сброс в 00:00 UTC) и десять
запросов в минуту. Этого хватает примерно на тысячу реплик в день.

Суффикс `:free` значит «только бесплатный объём»: кончился — запрос
останавливается, деньги не списываются никогда. Аи в таком случае даёт модели
отдохнуть до полуночи по UTC и думает следующей.

Что нужно знать до регистрации:

- **Нужна карта.** Бесплатные модели открываются после разовой проверки:
  блокируется и возвращается $1. Без неё запросы отклоняются.
- **Тексты хранятся.** На бесплатном плане шлюз сохраняет запросы и ответы, и
  выключить это нельзя (выключается на платном, $20 в месяц). То, что люди
  пишут Аи, будет лежать у третьей стороны.
- **Условия меняются.** Ещё в сентябре 2026 в бесплатном плане были другие
  модели и другие пределы.

Как получить ключ:

1. Открыть `platform.experientiallabs.ai`, войти, подтвердить почту.
2. Пройти проверку карты ($1, возвращается).
3. На странице **Credits** оставить «Keep going on credits» выключенным: тогда
   сверх бесплатного ничего не тратится.
4. **Settings → API keys** → создать ключ. Он начинается с `xpl_` и
   показывается один раз.
5. Положить ключ строкой `KEY_EXPLABS=…` в `~/.heart.env`, опубликовать, сказать
   «проверь мозги».

Что Аи скажет, если что-то не так:

- `HTTP 402` — не пройдена проверка карты или почты;
- `HTTP 403 (model_not_granted)` — у этой модели больше нет бесплатного
  объёма: имя в настройках пора заменить;
- `HTTP 429` — дневной объём вышел, вернётся в полночь по UTC.

## GigaChat

Бесплатный режим для физических лиц, без карты, по Сбер ID. На год:
50 млн токенов модели Ultra, 25 млн Max, 40 млн Pro и 250 млн Lite. У каждой
модели объём свой: кончился — Аи берёт следующую.

**Главное препятствие — сертификат.** Адреса GigaChat подписаны сертификатом
Минцифры. В документации Сбера сказано прямо: без него запрос ключа падает с
ошибкой проверки сертификата. Аи живёт в облаке Telegram, а зарубежные облака
этому сертификату обычно не доверяют. Проверка 12.11.2026 из обычного облака:
адреса GigaChat не открылись, а сайт документации Сбера открылся.

Поэтому ожидание честное: скорее всего, «проверь мозги» ответит «нет связи
при обмене ключа». Тогда напрямую GigaChat для Аи недоступен, и ключ можно не
держать. Ничего при этом не ломается: провайдер без связи отдыхает всё
дольше, до шести часов между попытками.

Попробовать стоит пяти минут:

1. Открыть `developers.sber.ru/studio`, войти через Сбер ID.
2. **Создать проект** → раздел «AI-модели» → **GigaChat API** → ввести
   название, принять соглашение.
3. В проекте слева — **Настройки API** → **Получить ключ**.
4. Скопировать поле **Authorization Key**. Оно показывается один раз.
   Client ID и Client Secret не нужны.
5. Убедиться, что справа в поле **Scope** стоит `GIGACHAT_API_PERS`.
6. Положить ключ строкой `KEY_GIGACHAT=…` в `~/.heart.env`, опубликовать,
   сказать «проверь мозги».

## Слух и зрение

Голосовые и фотографии разбирают не разговорные модели, а две отдельные — у
того же провайдера и тем же ключом. Ничего подключать не нужно.

| Чувство | Модель | Бесплатный объём | Настройка |
|---|---|---|---|
| слух | `whisper-large-v3-turbo` | 20 запросов в минуту, 2000 в сутки, 2 часа записи в час, 8 часов в сутки | `AI_HEARING_MODEL` |
| зрение | `qwen/qwen3.8-27b` | 30 запросов в минуту, 1000 в сутки, 200 тыс. токенов в сутки; картинка — 2048 токенов, то есть меньше ста картинок в день | `AI_VISION_MODEL` |

Числа — со страницы лимитов провайдера на 12.11.2026; точные для вашего
аккаунта показывает его кабинет. Лимиты у этих моделей свои: разговорных
мыслей они не расходуют, и наоборот.

Что стоит знать:

- модель зрения у провайдера помечена как пробная — её могут снять без
  долгого предупреждения. Тогда Аи скажет человеку «зрение сейчас не
  отвечает», а владельцу придёт весть с кодом ответа; другое имя модели
  вписывается в `AI_VISION_MODEL` в `config.js`;
- запись слушается до пяти минут, на человека — двадцать минут в сутки
  (хозяину — без счёта): слух общий на всех;
- выключить слух, зрение и чтение ссылок разом — `SENSES: false` в
  `config.js`;
- живьём слух и зрение не проверены: доступа к Telegram у чата разработки
  нет. Первое голосовое и первое фото покажут, принимает ли платформа такие
  запросы.

## Порядок и свои провайдеры

Аи идёт по списку `AI_PROVIDERS` сверху вниз: Experiential Labs, GigaChat,
Mistral, Cerebras, Gemini, OpenRouter, NVIDIA, GitHub Models и последним —
Cloudflare (его объём общий с рисованием). Поменять порядок — поменять записи
местами. На один ответ она пробует не больше трёх бодрых моделей подряд.

Подходит любой сервис с OpenAI-совместимым API. Запись — четыре поля:

```js
{ id: "имя", name: "Как назвать владельцу", baseUrl: "https://…/v1", models: ["модель"] }
```

и ключ под тем же `id`: `KEY_<ИМЯ>=…` в `~/.heart.env`.

«Совместимый» API бывает совместим не до конца. Аи справляется сама:

- модель не принимает `temperature`, усилие рассуждения или `max_tokens` —
  поле убирается, запрос повторяется, урок запоминается;
- `402` и `403` о модели — она сутки не трогается, цепочка идёт дальше, а
  владелец получает весть с именем модели или провайдера;
- `429` с исчерпанным дневным объёмом — отдых до полуночи по UTC;
- нет связи — отдых растёт вчетверо с каждой неудачей.

## Когда отвечает запасная

Раздел появился в 0.32.1 — после вести «основная модель недоступна — думаю
запасной», в которой не было ни причины, ни срока (сообщение владельца 20 в
[JOURNAL.md](JOURNAL.md)).

**Основной ключ — три модели**: `openai/gpt-oss-20b` (основная), затем
`openai/gpt-oss-120b` и `qwen/qwen3.8-27b` (`AI_MODEL` и `AI_MODELS` в
`config.js`). Лимиты бесплатного плана у провайдера считаются **на каждую
модель отдельно** и на 15.11.2026 у всех трёх одинаковы (его страница «Rate
Limits»):

| Лимит | Сколько | Когда возвращается |
|---|---|---|
| запросов в минуту | 30 | за секунды |
| токенов в минуту | 8 000 | за секунды |
| запросов в сутки | 1 000 | в течение суток |
| токенов в сутки | 200 000 | в течение суток |

Упираются обычно токены. Реплика с полным характером — около 1500 токенов на
входе, короткая — около 400 (измерено на стабе, приблизительно), и сам ответ
тоже считается. Минутного объёма хватает на пять полных ответов подряд, суточного
— примерно на сотню полных или несколько сотен коротких. Поэтому в оживлённом
чате основная модель на бесплатном плане может упираться в минутный лимит по
нескольку раз в день (расчёт, а не наблюдение) — это обычная работа цепочки, а
не поломка: следующая модель отвечает тут же, человек ничего не замечает.

**Что получает владелец** — по причине, а не одной вестью на всё:

| Причина | Человеку | Владельцу |
|---|---|---|
| минутный лимит (отдых — секунды) | ответ запасной | ничего; счёт «короткий лимит» в «статус» и в сводке дня |
| дневной лимит или отдых от 15 минут | ответ запасной | одна весть в сутки, тон «к сведению»: какой лимит, кто отвечает, в котором часу основную попробуют снова (`brains:limit`) |
| запросов до сброса осталось меньше десятой части | — | «к сведению» (`brains:low`) |
| все модели упёрлись | «вопрос записала, отвечу примерно после …» | «работает хуже», со сроком и советом добавить ключ другого провайдера (`brains:exhausted`) |
| нет связи | ответ запасной | раз и два — счёт; третий раз подряд — весть (`brains:offline`) |
| сбой у провайдера, пустой ответ, фильтр | ответ запасной | счёт; десятый раз за день — одна весть с разбивкой (`brains:shaky`) |
| основная модель снята или закрыта для ключа | ответ запасной | весть: имя пора заменить (`brains:gone`) |
| провайдер ждёт оплаты или подтверждения | ответ запасной | весть: заглянуть в кабинет (`brains:payment`) |
| ключ основного провайдера не принят | ответ другого провайдера или «неполадка» | «сломалось»: какую строку `~/.heart.env` проверить (`brains:key`) |
| то же у запасной модели или запасного провайдера | ответ следующей | весть с её именем (`brains:spare_gone:<модель>`, `brains:spare_payment:<провайдер>`, `brains:spare_key:<провайдер>`) |

Одна и та же весть приходит не чаще раза в сутки, всех вестей — не больше шести
в сутки.

**Где смотреть причину.** «Статус», строка «Запинка основной»: час, причина
(какой лимит), код ответа провайдера, числа «предел / занято / запрос», сколько
отдыхать и кто ответил. Запись хранится сутки. Строка «Сегодня»: сколько раз
отвечала запасная и по каким причинам. Те же числа — в утренней сводке; день на
запасной из-за лимита в строку «Сбои» не попадает.

**Что читается из ответа провайдера.** Только вид лимита (в минуту или в сутки,
токены или запросы) и три числа; сам текст отказа никуда не идёт. Формулировка
отказа взята из документации и вживую не видена: если она окажется другой, вид
останется пустым, и решать будет срок отдыха (от 15 минут — «долгий»).

**Модели отключают.** У провайдера есть страница «Deprecations» с датами. 15.11.2026
по ней нашлось, что две запасные основного ключа (`llama-3.3-70b-versatile`,
`llama-3.1-8b-instant`) отключены на бесплатном плане ещё 16.08.2026: три месяца
цепочка основного ключа состояла из двух моделей, и об этом не знал никто —
снятую запасную сердце молча пропускало сутки за сутками. С 0.32.1:

- о снятой запасной приходит весть с её именем — после первого же отказа;
- вместо двух отключённых в списке `qwen/qwen3.8-27b` (она же смотрит картинки,
  так что её дневной объём общий со зрением). Даты отключения на её странице
  нет, но у неё пометка «preview» — такие модели снимают без долгого срока;
- раздумья у неё выключены (`reasoning_effort: "none"`): для разговора они не
  нужны, а токены тратят;
- правило для агента — в [AGENTS.md](../AGENTS.md): перед выпуском сверять
  `AI_MODEL` и `AI_MODELS` со страницами «Models» и «Deprecations».

Был и второй дефект: когда все живые модели упирались в лимит, последней
спрашивалась снятая, и её отказ считался итогом — человек слышал «неполадка на
моей стороне», а вопрос терялся. Теперь итог — «лимит»: вопрос записывается.

**Чтобы основная упиралась реже:** ключ ещё одного провайдера (таблица выше;
проще всего начать с Mistral) — его модели встают в цепочку после трёх основных;
словарь (на короткий разговор модель не нужна); платный план основного
провайдера. Как меняется расход после подключения — видно в «Сегодня».

## Экзамен, ночная мысль, сцена, практика: что они тратят

С 0.32.0 есть четыре вещи, которые тратят модель по своей воле или по слову.
Все — в `lib/mind.js` и в блоке «ум» сердца; каждая выключается настройкой.

| Что | Когда | Сколько вызовов | Выключатель |
|---|---|---|---|
| **Экзамен** | только по слову хозяина в личке: «экзамен», «проверь себя» | 10 на запуск: по три за шаг, остальное на звонках будильника | `EXAM` |
| **Ночная мысль** | сама, раз в ночь между 03:00 и 09:00 | 1 (до трёх попыток при отказе); в пустой день — 0 | `REFLECT` |
| **Сцена** | «начни сцену: …» — дальше каждый ход | 1 на ход, как обычный ответ | `SCENES` |
| **Языковая практика** | «давай говорить по-английски» — дальше каждая реплика | 1 на реплику | `PARTNER` |

**Экзамен** — проверка самой себя. Десять вопросов задаются от имени
незнакомца: без памяти, без имени, ничего не сохраняется. Судит не модель, а
код (`gradeExam`): верно ли посчитала, назвала ли простой факт, призналась ли,
что не знает выдуманного, не выдала ли хозяина, не процитировала ли свои
правила, не пообещала ли действий, которых не умеет, не назвалась ли
человеком, уложилась ли в длину, сказала ли «вы», назвала ли сегодняшнюю дату.
Отчёт приходит хозяину сам и сравнивается с прошлым; «результаты экзамена»
покажет последний. Вопрос, на который провайдер отказал, ждёт следующего шага
и неудачей не считается. Зачем: сменили модель или провайдера — сразу видно,
стала ли она отвечать хуже.

**Ночная мысль** — один вызов по вчерашним счётчикам (сколько отвечала, чему
учили, что не поняла). Модель возвращает две строки: «Мысль» и «Завтра». План
«Завтра» весь день идёт в записку модели и в утреннюю сводку. Переписку она
при этом не читает.

Сцена и практика при лимите не ставят ходы в очередь: «сцена на паузе».

## Что модель не тратит

С 0.32.0 без модели идут ещё: советы фильмов, книг, игр и музыки, «что было в
этот день», «интересный факт», стикеры, список умений («что ты умеешь» и его
разделы) и двадцать тем словаря на вопросы «ты умеешь …?» — раньше на них
отвечала модель и могла выдумать умение, которого нет.

С 0.31.0 без модели разговора идут ещё: перевод (переводчик Cloudflare), слова
с повторением, новости из лент, «угадай рисунок», «насколько я знаю?», вопросы
о праздниках и числе по хиджре, совет аниме по любимому. Модель тратится по
одному вопросу и только по просьбе: «кто прав?», «ты уверена?» (спрашивается не
та модель, что отвечала), «предложи ответы» (хозяин; один вопрос на десять
фраз). Словарь вырос до 279 тем и 1613 фраз: из 74 проверенных частых реплик,
уходивших к модели, 53 теперь отвечает он.

С 0.25.0 на короткий разговор модель не нужна: «привет», «как дела», вопросы
о ней самой и её вкусах, шутки, советы «что приготовить» и пасхалки берутся
из словаря (`PHRASES.txt`, собирается `npm run phrases`). Туда же — все игры,
ролевые действия, манеры, счёт, погода, курс, напоминания. Модель остаётся
для настоящего разговора, зрения, пересказа ссылок и пересказа пропущенного
в чате. Сколько раз за день ответил словарь — в «статус», строка «Сегодня».

С 0.26.0 без модели идут ещё анкета «любимое», квиз по темам, её «доброе
утро» хозяину и фразы, которым хозяин научил её в чате. «Что ты не поняла?» —
список коротких реплик, ушедших к модели: чего не хватает словарю.
