# Запасные мозги: как подключить ключ

Аи думает цепочкой: основные модели (ключ `AI_PROVIDER_KEY`), затем запасные
провайдеры по порядку из `AI_PROVIDERS` в `tgcloud/lib/config.js`. Запасной
провайдер без ключа спит и ничего не стоит. Чтобы его разбудить, нужен только
ключ — код уже написан.

Условия провайдеров меняются. Здесь записано то, что проверено по их
документации 12.11.2026.

## Куда кладётся ключ

Все ключи запасных провайдеров лежат в **одном** секрете GitHub — `AI_EXTRA_KEYS`.
Это строка в формате JSON: имя провайдера и его ключ.

```json
{"explabs":"xpl_…","gigachat":"…"}
```

Один провайдер — одна пара. Имена — строго такие, как в таблице ниже.

С телефона:

1. GitHub → репозиторий `Ai` → **Settings** → **Secrets and variables** →
   **Actions**.
2. Найти, где уже лежит `AI_PROVIDER_KEY` (вкладка *Secrets*, список
   репозитория или окружение `heart-serverless`), и там же создать или
   изменить секрет `AI_EXTRA_KEYS`.
3. Вставить строку JSON целиком, в одну строку, с фигурными скобками.

Ключ попадает в Аи только при публикации: после изменения секрета нужно
опубликовать сердце (слияние в `main` или Actions → Heart → Run workflow →
`deploy`).

Проверка — сказать Аи **«проверь мозги»**. Она отправит по одному живому
запросу каждой модели и назовёт, кто отвечает, а кто нет и почему.

| Провайдер | Имя в JSON | Модели | Что нужно для ключа |
|---|---|---|---|
| Experiential Labs | `explabs` | `deepseek-v4.1-flash:free`, `gpt-6-luna:free` | почта и проверка карты |
| GigaChat | `gigachat` | `GigaChat-3-Ultra`, `GigaChat-2-Max`, `GigaChat-2-Pro`, `GigaChat-2` | Сбер ID |

## Experiential Labs

Шлюз с OpenAI-совместимым API. В бесплатном плане две разговорные модели:

| Модель | Что это |
|---|---|
| `deepseek-v4.1-flash:free` | DeepSeek V4.1 Flash — быстрая, усилие рассуждения управляется |
| `gpt-6-luna:free` | GPT-6 Luna — младшая модель OpenAI |

Вместе они делят **миллион токенов в сутки** (сброс в 00:00 UTC) и десять
запросов в минуту. Этого хватает примерно на тысячу реплик в день.

Суффикс `:free` значит «только бесплатный объём»: кончился — запрос
останавливается, деньги не списываются никогда. Аи в таком случае даёт модели
отдохнуть до полуночи по UTC и думает следующей.

Что нужно знать до регистрации:

- **Нужна карта.** Бесплатные модели открываются после разовой проверки:
  блокируется и возвращается $1. Без неё запросы отклоняются.
- **Тексты хранятся.** На бесплатном плане шлюз сохраняет запросы и ответы, и
  выключить это нельзя (выключается на платном, $20 в месяц). То, что люди
  пишут Аи, будет лежать у третьей стороны.
- **Условия меняются.** Ещё в сентябре 2026 в бесплатном плане были другие
  модели и другие пределы.

Как получить ключ:

1. Открыть `platform.experientiallabs.ai`, войти, подтвердить почту.
2. Пройти проверку карты ($1, возвращается).
3. На странице **Credits** оставить «Keep going on credits» выключенным: тогда
   сверх бесплатного ничего не тратится.
4. **Settings → API keys** → создать ключ. Он начинается с `xpl_` и
   показывается один раз.
5. Положить в `AI_EXTRA_KEYS` под именем `explabs`, опубликовать, сказать
   «проверь мозги».

Что Аи скажет, если что-то не так:

- `HTTP 402` — не пройдена проверка карты или почты;
- `HTTP 403 (model_not_granted)` — у этой модели больше нет бесплатного
  объёма: имя в настройках пора заменить;
- `HTTP 429` — дневной объём вышел, вернётся в полночь по UTC.

## GigaChat

Бесплатный режим для физических лиц, без карты, по Сбер ID. На год:
50 млн токенов модели Ultra, 25 млн Max, 40 млн Pro и 250 млн Lite. У каждой
модели объём свой: кончился — Аи берёт следующую.

**Главное препятствие — сертификат.** Адреса GigaChat подписаны сертификатом
Минцифры. В документации Сбера сказано прямо: без него запрос ключа падает с
ошибкой проверки сертификата. Аи живёт в облаке Telegram, а зарубежные облака
этому сертификату обычно не доверяют. Проверка 12.11.2026 из обычного облака:
адреса GigaChat не открылись, а сайт документации Сбера открылся.

Поэтому ожидание честное: скорее всего, «проверь мозги» ответит «нет связи
при обмене ключа». Тогда напрямую GigaChat для Аи недоступен, и ключ можно не
держать. Ничего при этом не ломается: провайдер без связи отдыхает всё
дольше, до шести часов между попытками.

Попробовать стоит пяти минут:

1. Открыть `developers.sber.ru/studio`, войти через Сбер ID.
2. **Создать проект** → раздел «AI-модели» → **GigaChat API** → ввести
   название, принять соглашение.
3. В проекте слева — **Настройки API** → **Получить ключ**.
4. Скопировать поле **Authorization Key**. Оно показывается один раз.
   Client ID и Client Secret не нужны.
5. Убедиться, что справа в поле **Scope** стоит `GIGACHAT_API_PERS`.
6. Положить ключ в `AI_EXTRA_KEYS` под именем `gigachat`, опубликовать,
   сказать «проверь мозги».

## Порядок и свои провайдеры

Аи идёт по списку `AI_PROVIDERS` сверху вниз: сейчас сначала Experiential
Labs, потом GigaChat. Поменять порядок — поменять записи местами.

Подходит любой сервис с OpenAI-совместимым API. Запись — четыре поля:

```js
{ id: "имя", name: "Как назвать владельцу", baseUrl: "https://…/v1", models: ["модель"] }
```

и ключ под тем же `id` в `AI_EXTRA_KEYS`.

«Совместимый» API бывает совместим не до конца. Аи справляется сама:

- модель не принимает `temperature`, усилие рассуждения или `max_tokens` —
  поле убирается, запрос повторяется, урок запоминается;
- `402` и `403` о модели — она сутки не трогается, цепочка идёт дальше;
- `429` с исчерпанным дневным объёмом — отдых до полуночи по UTC;
- нет связи — отдых растёт вчетверо с каждой неудачей.
