лежит в репозитории, потому что чат не хранилище: по этим номерам владелец
выбирает, что делать, а новый чат продолжает с того же места.

**О GigaChat и Алисе (103).** GigaChat выдаёт доступ через обмен ключа на
получасовой токен и работает на сертификатах, которым платформа может не

карты и без проверок». Под это условие подходят сервисы с OpenAI-совместимым
API и бесплатным ключом — их условия нужно проверить перед подключением.

## Открытые вопросы к владельцу

1. **Слышит ли Аи канал моста.** В доме `Ai` есть только обработчик `message`,
   а посты канала платформа, судя по её документации, доставляет обработчику
   `channel_post`. Проверка: «покажи профиль» в живом боте. Если Аи отвечает
   «Юи не ответила…», а в канале при этом `"ok":true`, нужен второй обработчик
   (пять строк). Теперь это видно и без проверки: Аи сама напишет «Юи не
   ответила на мосту».
2. **Черта по играм** (см. раздел 76–100): строка в `PROJECT.md`, который
   меняется во всех копиях сразу.
3. **Перенос на полигон.** Правки сделаны прямо в доме `Ai`: доступа к
   `Ai-TEST` у этого чата нет.
