# Будильник

Платформа будит сердце только обновлением из Telegram. Всё, что должно
случаться «само» — напоминание в срок, утренняя сводка, отложенный ответ,
«буди меня в 7», — случается, когда Аи просыпается. Вопрос только в том, кто
её будит.

| Кто будит | Как часто | Что нужно |
|---|---|---|
| Любое сообщение ей | как повезёт | ничего |
| Actions (`Heart`, по расписанию) | раз в час | ничего: работает после слияния в `main` |
| Второй телефон или ноутбук | раз в минуту | этот файл |

Насколько точно её будят сейчас, Аи знает сама: строка «Будильник» в ответе
на «статус» и оговорка при постановке напоминания.

## Часовой будильник: Actions

Workflow `Heart` раз в час запускает `tgcloud run handlers/message '{}'
--ctx '{ tick: true }'`. Расписание GitHub выполняет только для ветки по
умолчанию, поэтому оно начинает работать после слияния в `main`. Настраивать
нечего.

- Запустить вручную: Actions → Heart → Run workflow → `tick`.
- Выключить: переменная репозитория `HEART_ALARM = off`.
- Стоит около минуты Actions за запуск — 720 минут в месяц из двух тысяч
  бесплатных. GitHub может задержать запуск на несколько минут.

Такой запуск исполняет код из репозитория, а не опубликованный. Если сборки
разные (в `main` одно, опубликовано с ветки другое), удар ничего не трогает и
пишет в журнал предупреждение: старый код не должен объявлять себя новым.

## Минутный будильник: второй телефон

Раз в минуту в канале «Мост» правится одно сообщение. Telegram сообщает об
этом Аи как о правке поста — и она просыпается.

**Отдельный бот не нужен.** О собственных сообщениях бот обновлений не
получает, поэтому Аи не может будить себя сама: говорить в канал должен кто-то
другой. В канале уже есть Юи — подойдёт её токен. Код Юи при этом не меняется:
телефон просто говорит в канал от её имени.

Одно стоит знать: токен Юи умеет всё, что умеет Юи. Он лежит только на вашем
телефоне, в файле, который читает один Termux. Если это не нравится, годится
любой другой бот-администратор канала — у бота, заведённого только ради
будильника, токен не умеет ничего, кроме как тикать.

### Один раз

1. Токен Юи: @BotFather → `/mybots` → Юи → **API Token**. Токен при этом не
   меняется, он просто показывается.
2. ID канала «Мост»: строка `ABILITIES_CHANNEL_ID` в
   `tgcloud/lib/config.js`.
3. На втором телефоне поставить Termux (из F-Droid) и выполнить:

   ```bash
   pkg install -y git gh curl
   gh auth login
   gh repo clone shironaki/Ai
   cat > ~/.heart-alarm.env <<'EOF'
   ALARM_BOT_TOKEN=токен Юи
   ALARM_CHAT_ID=числовой ID канала «Мост»
   EOF
   chmod 600 ~/.heart-alarm.env
   bash ~/Ai/scripts/alarm.sh
   ```

   Две строки внутри `EOF` заменить своими значениями.

Скрипт называет бота, от чьего имени идёт («Будильник идёт от имени @…»),
пишет в канал одно сообщение «⏰ 12.11 16:00:00» и дальше правит его раз в
минуту — канал не засоряется. Остановить — `Ctrl+C`; запустить снова —
последняя строка блока.

Чтобы телефон его не усыплял:

- в настройках Android снять с Termux ограничение батареи;
- скрипт сам вызывает `termux-wake-lock`, если он есть;
- для автозапуска после перезагрузки — приложение Termux:Boot и файл
  `~/.termux/boot/alarm.sh` с одной строкой `bash ~/Ai/scripts/alarm.sh`.

На ноутбуке то же самое работает в Git Bash.

### Проверка

Через две минуты сказать Аи «статус». Строка должна стать такой:

```
Будильник: будят каждую минуту — напоминания и сводка приходят в срок
```

Если осталось «будят раз в 60 мин» или «нет»:

- в файле указан токен самой Аи — скрипт называет имя бота при запуске;
- бот не администратор канала или не может править сообщения — скрипт после
  трёх неудач подряд напишет об этом сам;
- Аи не получает правки постов: в журнале публикации (шаг «Check the
  webhook») должно быть `edited_channel_post` в списке обновлений;
- в файле указан не тот канал.

### Настройки

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `ALARM_EVERY` | `60` | период в секундах, не меньше 20 |
| `ALARM_MODE` | `edit` | `edit` — править одно сообщение; `post` — новое вместо старого |

Каждый удар — один запуск сердца на платформе. Если у платформы появится счёт
запусков, период можно увеличить: `ALARM_EVERY=300` — раз в пять минут.

## Что делает один удар

1. Досылает владельцу вести, которые не ушли в прошлый раз.
2. Звонит напоминаниям, чей срок пришёл; повторяющиеся переносит на следующий
   срок.
3. Утром (после `DIGEST_HOUR`) отправляет сводку за вчера.
4. Досылает до трёх отложенных ответов, если есть чем думать.
5. Убирает устаревшее: ответы моста, запас источников, брошенные игры.

Людям удар ничего не пишет, если писать нечего.
